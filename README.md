# PT Entech Security Indonesia — Official Website

Modern, professional website for **PT Entech Security Indonesia**, the Indonesian subsidiary of Entech Pacific Pte. Ltd. (Singapore) and authorized distributor of world-class security brands.

## 🌐 Live Site
[https://knyf3.github.io/entech-security-website](https://knyf3.github.io/entech-security-website)

## 🏢 About PT Entech Security

PT Entech Security Indonesia is a premier supplier of professional security systems to system integrators and distributors across Indonesia. Established in 2012, we are the authorized distributor for:

| Brand | Products |
|---|---|
| **ACRE Security** | ACT Pro Access Control, SPC Intrusion Systems, ASC Smart Controllers |
| **Siemens SiPass** | SiPass Entro, SiPass Integrated |
| **DETEX** | V40 Exit Devices, Exit Push Bars, Door Prop Alarms |
| **Nedap** | uPASS Reach (long-range RFID), TRANSIT |
| **Kantech** | EntraPass Access Control |

## 🎨 Design

- **Color scheme:** Dark Navy (`#0A1628`) + Teal accent (`#00B4A0`) + Orange highlight (`#F5821F`)
- **Typography:** Space Grotesk (headings) + Inter (body)
- **Design system:** Modern corporate — clean, professional, minimal
- **Responsive:** Mobile-first, works on all screen sizes
